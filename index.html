Blog 03 / Interview Synthesis

From AI Creativity
to 3D Agents

What interviews about creativity evaluation taught us—and why those findings now point toward strategy discovery in simulated worlds.

03

Contents

1. Defining the Phenomenon 2. Reframing the Phenomenon 3. Situating the Phenomenon

Over the past few months, we interviewed researchers working across AI creativity, open-ended exploration, human–AI co-creation, and agent evaluation. We began with a question that seemed straightforward: how should we evaluate creativity in AI agents?

The more conversations we had, the clearer it became that creativity is not a single capability that can be measured outside of context.

1. Defining the PhenomenonWhat the interviews revealed

1.1 Comparing the Definitions

We initially assumed that disagreements about AI creativity came mainly from differences in measurement. The interviews showed us that researchers were often studying different objects from the start.

In Cheng Qian’s EscapeBench and CreativityBench, creativity is closer to unconventional but effective tool use: can an agent discover a solution that was not directly suggested within a constrained action space?

Antonios Liapis’s work showed us why creativity in human–AI co-creation cannot be reduced to a final artifact. An AI suggestion may never be adopted directly, yet still change how a designer understands the problem and lead to a new direction later. Creativity can therefore live in interaction, selection, and shifts in direction.

Vijeta Deshpande places different creativity tasks within a unified evaluation framework to test whether they reflect a shared model capability. She found strong relationships between model performance across tasks, but this general capability still cannot explain why a result matters within a particular professional context.

When researchers discuss creativity, they may be referring to outputs, strategies, exploration processes, human–AI interaction, or cross-task capability. These concepts overlap, but they are not the same object of measurement.

1.2 Comparing the Evaluations

Researchers not only define creativity differently; they also observe it at different levels.

The first level evaluates outcomes: did the agent complete the task, is the work novel and useful, and did the model achieve a higher benchmark score? Outcomes are easy to compare, but they reveal little about how a solution emerged.

The second level evaluates observable behavior: which tools did the agent use, what strategy did it follow, and did it meaningfully depart from the common path? This is closer to the “different solutions” we care about, but it can still mistake random behavior for exploration.

The third level evaluates process: which directions did the agent try, how did it respond to failure, and what caused it to change strategy? In human–AI co-creation, this also includes how a suggestion was adopted, transformed, or indirectly influenced the creator’s thinking.

These levels answer three different questions: what result was produced, what method was used, and how that method was discovered.

1.3 Identifying the Limitations

Despite their different objects and methods, the interviews repeatedly surfaced two limitations.

First, benchmarks struggle to maintain a stable connection to real use. A general score can rank models, but it may not tell a product team who the model helps, what task it improves, or how it changes human judgment. Rapid model development also leaves benchmarks vulnerable to becoming outdated, under-maintained, or overlooked by industry.

Second, evaluating only the final result loses the delayed value of exploration. An action that does not immediately improve success may reveal a new object property, spatial relationship, or causal clue that later becomes a critical stepping stone.

These limitations suggest that we need more than a better abstract metric. We need a bounded world in which feasibility, difference, and value can be observed.

2. Reframing the PhenomenonWhat we chose to preserve

2.1 Preserving the Evidence

Moving away from a universal creativity score does not mean discarding the earlier research. The interviews helped us preserve three forms of evidence that can travel across domains:

Outcome
Whether the agent solved the problem and whether the result was effective and reproducible.
Behavior
Which strategy the agent used and whether it truly differed from the common solution rather than merely changing action order or adding random variation.
Process
How the agent explored, failed, gathered information, and changed direction—and whether an early attempt became valuable later.

Together, these forms of evidence describe whether the task was completed, whether the method was different, and how the new method emerged.

2.2 Separating the Judgments

Using this evidence, we can replace the broad judgment “Is this behavior creative?” with three more specific judgments:

Feasible
Does the solution respect spatial, object, and task constraints, and can it actually be executed in the environment?
Different
Does the solution change the tools, action relationships, or strategic logic rather than offering only a surface variation?
Valuable
Does the difference complete the task, open a new reachable state, or create a strategy that can transfer?

We care about the intersection: a solution that was not explicitly anticipated, yet remains workable and produces value.

2.3 Reformulating the Question

With this understanding, “How should we evaluate creativity in AI agents?” no longer works as our starting point. It assumes that creativity is a stable property that can be isolated and measured within a model, which repeatedly pulls the discussion back toward definitions.

We now ask: can an agent discover a way to solve a problem that was not explicitly anticipated, yet is feasible, different, and valuable?

The project therefore moves from general, cross-domain creativity evaluation toward strategy discovery within a specific environment.

3. Situating the PhenomenonWhy the next setting is three-dimensional

3.1 Introducing the Bridge

Qiancheng’s research provides a key bridge for this transition.

In EscapeBench, an agent uses available objects and actions to complete escape-room-like tasks inside a constrained environment. The evaluation asks whether the agent ultimately reaches the goal without prescribing the correct intermediate action, preserving an objective outcome while allowing multiple solution paths.

CreativityBench extends this idea by focusing on unconventional object use. Rather than deciding in advance whether the agent “has creativity,” researchers can observe whether it discovers an unusual but effective use of a tool.

This design sits between a closed benchmark and a completely open creative task: it combines a clear goal with an open solution space. Qiancheng’s work demonstrates an important path—rather than assigning creativity a score directly, construct an environment in which relevant behaviors can emerge and leave verifiable consequences.

3.2 Extending the Environment

Extending this approach into 3D simulation gives us richer behavioral evidence within explicit constraints.

An agent must understand spatial relationships, move and combine objects, test assumptions about their functions, and adjust its strategy using environmental feedback. Complete trajectories can be recorded and replayed, while layouts, object properties, and task conditions can be systematically changed.

We can therefore observe not only whether an agent finishes the task, but whether it discovers new tool combinations, updates its behavior after failure, or repeatedly converges on the same path as other agents.

3D simulation also supports transfer evaluation. By changing spatial structure or surface features while preserving deeper causal relationships, we can test whether an agent is mechanically replaying actions or has learned a principle that transfers.

Qiancheng’s research helps us ask whether an agent can find an unconventional but effective solution. 3D simulation lets us continue: how did that solution emerge, and can the underlying strategy transfer?
